--------------------------------------------------------------------------
 4) CÓDIGO CLAVE DE LA SUITE
--------------------------------------------------------------------------
backend/main.py
    Backend FastAPI: API REST, auth (token), proxy MiR, control de
    contenedores, /api/ur/move (validación + recovery + auto-resend del
    programa externo), payload, freedrive.

scripts/joint_mover.py
    Arma y envía la trayectoria al controlador (FollowJointTrajectory).
    Trayectoria de 1 punto + lenta (evita el speed limit), detección de
    no-op, timeouts ampliados.

scripts/joint_server.py
    El "pizarrón": servidor HTTP :9091 suscrito a /joint_states, sirve el
    último valor en JSON (para la web).

scripts/mir_liveness.py          Heartbeat del puente MiR (desde /odom)
scripts/mir_watchdog.sh          Watchdog del puente (gracia + señal real)
scripts/mir_entrypoint.sh        Arranque del contenedor del puente MiR
scripts/ur_start.sh              Inicia el driver UR (duo_ur)
scripts/mir_raw.py               Puente ROS1->ROS2 (CÓDIGO DE EEMIL - no tocar)

web/src/components/Viewer3D.svelte    Visor 3D (torso simulado + brazos)
web/src/components/UrPanel.svelte     Panel de brazos (botones de codo)
web/src/components/SkillsPanel.svelte Payload + freedrive (requisito >1 kg)
